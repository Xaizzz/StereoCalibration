# 📷 StereoCalibration - Система Стереокалибровки Камер

Профессиональное приложение для стереокалибровки двух камер с возможностью измерения расстояний в реальном времени с помощью ArUco маркеров.

[![OpenCV](https://img.shields.io/badge/OpenCV-4.10.0-green.svg)](https://opencv.org/)
[![License](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

## 🎯 Возможности

### 🔧 Основной функционал

- **Автоматическое обнаружение камер** в системе
- **Предварительный просмотр камер** с проверкой работоспособности
- **Стереокалибровка** на основе шахматной доски
- **Измерение расстояний** до ArUco маркеров в реальном времени
- **Оценка качества калибровки** с рекомендациями
- **Сохранение/загрузка** результатов калибровки

### 📊 Технические особенности

- **Высокоточная калибровка** с субпиксельной точностью
- **Триангуляция 3D координат** объектов
- **Исправление искажений** линз камер
- **Автоматическая оценка** качества калибровки
- **Интуитивный интерфейс** с подробными инструкциями

## 🚀 Быстрый старт

### Требования

- **Windows 10/11** (x64)
- **.NET 8.0** или новее
- **Две USB камеры** или веб-камеры
- **Шахматная доска** для калибровки (9x6 углов, размер квадрата 8.5мм)

### Установка

1. **Клонирование репозитория:**

```bash
git clone https://github.com/your-username/StereoCalibration.git
cd StereoCalibration
```

2. **Восстановление зависимостей:**

```bash
cd calibr
dotnet restore
```

3. **Сборка проекта:**

```bash
dotnet build --configuration Release
```

4. **Запуск приложения:**

```bash
dotnet run
```

### Первое использование

1. **Подключите две камеры** к компьютеру
2. **Запустите приложение** - откроется окно выбора камер
3. **Выберите камеры** и проверьте их работу кнопкой "Предпросмотр"
4. **Нажмите "Применить"** для перехода к основному интерфейсу

## 📝 Инструкция по использованию

### 🎯 Этап 1: Калибровка

1. **Подготовьте шахматную доску** (9x6 углов, размер квадрата 8.5мм)
2. **Нажмите "Начать"** для активации видеопотока
3. **Поместите доску** в поле зрения обеих камер
4. **Нажмите "Захватить пару"** когда доска обнаружена (подсветится зеленым)
5. **Повторите шаг 4** для **10-15 различных позиций** доски:
   - Разные углы наклона
   - Различные расстояния
   - Покрытие всей области кадра
6. **Нажмите "Калибровать"** для запуска процедуры

### 📏 Этап 2: Измерения

После успешной калибровки:

1. **Разместите ArUco маркеры** в поле зрения камер
2. **Приложение автоматически** вычислит расстояния до маркеров
3. **Результаты отображаются** на экране в миллиметрах

### 📊 Оценка качества

Приложение автоматически оценивает качество калибровки:

- 🟢 **< 0.5 пикселей** - Отличное качество
- 🟡 **0.5-1.0 пикселей** - Хорошее качество
- 🟠 **1.0-2.0 пикселей** - Удовлетворительное
- 🔴 **> 2.0 пикселей** - Требуется перекалибровка

## 📚 Дополнительная информация

### 🔬 Научная основа

Приложение основано на классических алгоритмах компьютерного зрения:

- **Калибровка камер** по методу Zhang
- **Стереокалибровка** с оптимизацией параметров
- **Триангуляция** с использованием DLT (Direct Linear Transform)
- **Исправление искажений** радиального и тангенциального типов

### 🎓 Применение

- Измерение размеров объектов
- 3D сканирование
- Робототехника и навигация
- Контроль качества в производстве
- Исследования в области компьютерного зрения

### 🐛 Устранение неполадок

**Проблема:** Камеры не обнаруживаются

- Проверьте подключение USB
- Убедитесь, что камеры не используются другими приложениями
- Перезапустите приложение

**Проблема:** Высокая ошибка калибровки

- Используйте больше изображений (15-20)
- Убедитесь в неподвижности камер
- Проверьте качество фокусировки
- Используйте различные позиции доски

**Проблема:** Неточные измерения

- Проведите повторную калибровку
- Убедитесь в правильности размера квадратов доски
- Проверьте освещение сцены
